Place production-ready bag maker assets in this directory:

- `nco-logo.png`
- `bag-template-overlay.png`
- `bag-shape-mask.png`

V1 does not require these files to exist at build time.

- If `nco-logo.png` is missing, the app falls back to `/images/nco-mark.png`.
- The overlay and mask files are optional until final production artwork is available.
